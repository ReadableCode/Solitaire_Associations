# Third-party assets

`app/static/img/emoji/*.svg` are unmodified glyphs from
[googlefonts/noto-emoji](https://github.com/googlefonts/noto-emoji),
fetched by `scripts/fetch_emoji_assets.py`.

Upstream licensing (per their README): fonts are OFL 1.1, tools and most
image resources Apache-2.0, region flags public domain. The repo's LICENSE
file at fetch time is vendored here as `NOTO_EMOJI_LICENSE`.
